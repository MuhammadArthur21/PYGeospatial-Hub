# Getting Started with PyGeospatial Hub

## Welcome!

PyGeospatial Hub is your one-stop platform for Python geospatial analysis.
This guide will help you get started quickly.

## Step 1: Explore Libraries

Navigate to the **Libraries** page to browse the catalog of 37+ geospatial libraries.
Each library has documentation, code examples, and a "Try in Sandbox" button.

## Step 2: Write Code in Sandbox

The **Sandbox** is an interactive coding environment where you can write and execute
Python geospatial code directly in your browser.

1. Select libraries from the left sidebar
2. Write your code using the Monaco Editor
3. Click **Run** to execute
4. View results in the output panel

## Step 3: Use Pre-built Tools

The **Tools Marketplace** provides ready-to-use geospatial operations:
- Buffer Geometry, Clip Raster, Geocode Address
- Distance Calculator, Merge Files, Spatial Join
- And more...

## Step 4: Save and Share

Save your scripts and share them with the community.
Track your executions and datasets in the **Dashboard**.

## Need Help?

Check the **Documentation** page for API references and guides.
Visit the **Tutorials** page for step-by-step learning paths.
