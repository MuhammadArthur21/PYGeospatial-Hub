# PyGeospatial Hub User Guide

## Getting Started

### Browsing Libraries
1. Navigate to the **Libraries** page
2. Browse by category or use the search bar
3. Click on a library to view details, documentation, and code examples
4. Click **"Try in Sandbox"** to instantly open a pre-configured coding environment

### Using the Sandbox
1. Go to the **Sandbox** page
2. Select the libraries you need from the left sidebar
3. Write or paste Python code in the editor
4. Click **"Run"** to execute your code
5. View output and results in the right panel

### Tools Marketplace
1. Browse pre-built tools by category
2. Click on any tool to use it in the sandbox
3. Tools provide ready-to-use geospatial operations

### Saving Your Work
1. From the sandbox, click **"Save Script"**
2. Your scripts appear in the **Dashboard**
3. You can share scripts publicly or keep them private
